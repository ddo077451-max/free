# Конференции.РФ — проект для демонстрационного экзамена 09.02.07 (2027)

Стек: **HTML + CSS (+ Bootstrap) / Python Flask / SQLite / SQL**. Запуск: `pip install flask` → `python app.py` → http://localhost:5000

## Структура и что делает каждый файл (ТЗ)

| Файл | Что делает | Задание |
|---|---|---|
| `app.py` | Бэкенд: маршруты, валидация, работа с БД, права доступа, CRUD заявок, смена статусов | 1.1, 1.5, 3.2, 3.4 |
| `schema.sql` | Создание таблиц `users` и `requests`, связь 1→N, проверки значений | 1.5, 3.2, 3.7 |
| `templates/base.html` | Общий шаблон: `lang="ru"`, `header`/`nav`/`main`/`footer`, подключение CSS и Bootstrap | 3.1, 3.5 |
| `templates/register.html` | Регистрация: логин (лат+цифры ≥6), пароль ≥8, ФИО (кириллица), телефон `8(XXX)XXX-XX-XX`, e-mail; ошибки на форме; `data-testid="reg-*"` | 1.2 |
| `templates/login.html` | Вход, сообщение об ошибке, ссылка «Еще не зарегистрированы? Регистрация»; `data-testid="login-*"` | 1.2 |
| `templates/request_form.html` | Создание/редактирование заявки: помещение (текст), дата (текст), оплата (select); `data-testid="req-*"` | 1.3, 3.2 |
| `templates/requests.html` | Мои заявки (`req-list`), отзыв (`req-review`, активен только при «Завершено»), изменить/удалить | 1.3, 3.2 |
| `templates/admin.html` | Панель админа: все заявки (`admin-row`), смена статуса (`admin-status`), фильтр по статусу | 1.4, 3.4 |
| `static/style.css` | Единый стиль, адаптив 390×844, анимации и hover-эффекты | 2.1, 3.1, 3.6 |
| `db_diagram.svg` | ER-диаграмма (положить в папку проекта) | 3.7 |
| `api4/app.py` | Модуль 4: `GET /orders`, обработка данных, фильтры `status`/`user_id`, ошибки 400/500, порт 8080 | 4.2–4.5 |

## Правила работы (логика из ТЗ)
- Админ: логин `Conf2027`, пароль `Demo77` (создаётся при старте в `init_db`). Вход на той же странице входа → перенаправление в `/admin`.
- Статусы: `Новая` → `Мероприятие назначено` → `Завершено`.
- Оплата: `При очном посещении` / `Перевод по СБП`.
- Дата принимается как `ДД.ММ.ГГГГ` или `ГГГГ-ММ-ДД`, хранится ISO.
- CSRF-защиты нет — автотест сможет отправлять формы.

## Перед экзаменом
1. Скопируйте `bootstrap.min.css` из публичной папки сервера в `static/vendor/` (интернета не будет, задание 3.3 ищет библиотеку).
2. Модуль 4: откройте `Прил_4` и сверьте имена таблиц/полей и русские названия статусов с `api4/app.py` (блок SCHEMA / STATUS_RU). Дамп `shop_db.sql` для SQLite: `sqlite3 shop.db < shop_db.sql`.
3. Для задания 4.4 при нескольких БД задайте `DB_PATH`.
